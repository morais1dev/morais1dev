### 🚀 Projeto em destaque

#### 🏷️ [Tagger](https://github.com/morais1dev/Tagger) — Editor de metadados de música

Uma alternativa ao MP3Tag com interface moderna. A ideia surgiu da vontade de deixar as tags dos meus arquivos iguais a como são registradas (scrobbled) no Last.fm.

- 🔎 Busca de metadados no **MusicBrainz**,**Last.fm** e **Discogs**
- 🖼️ Capas via **Cover Art Archive**
- 📂 Organização automática de arquivos em pastas
- 🎵 Integração com **Last.fm** e **Discogs**

`Python` · `GUI desktop` · `APIs REST`
